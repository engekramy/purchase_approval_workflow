How It Works

Three simple steps from purchase request to confirmed order.

📋

1. Submit for Approval

The buyer clicks Submit for Approval. The workflow engine matches the order against the Approval Matrix and routes it to the correct approver at the correct level.
✅

2. Approve or Reject

The approver acts directly from Odoo or from the one-click email link. Multi-level orders advance automatically to the next level on approval.
📦

3. Auto-Confirm

Once all required approvals are collected, the purchase order is automatically confirmed and the buyer is notified. Every step is recorded in the immutable audit trail.

Security & Architecture

Built with production security standards from day one.

🔑

Role-Based Access

Three security groups — Approval User, Approval Manager, and Administrator — with fine-grained record rules. Approvers can only act on orders assigned to them.

🛡️

XSS-Safe HTML

All user-controlled data (vendor names, rejection reasons, order references) is HTML-escaped before being embedded in email links or chatter messages.

🔒

Secure Email Tokens

One-click email approval links use secrets.token_urlsafe(32) (43-character cryptographic tokens) and are validated server-side before any action is taken.

📜

Immutable Audit Trail

Approval history records are write-protected after creation — even administrators cannot alter past decisions. Full timestamps and approver identity are always preserved.

🚫

No Info Disclosure

Internal exception details are logged server-side only. Public-facing error pages show generic messages — no stack traces or field names are ever exposed to end users.

Installation

  1. Download and extract the module into your Odoo addons directory.
  2. Install the xlsxwriter Python package on your server:
    pip install xlsxwriter
  3. Restart the Odoo server.
  4. In Odoo, go to Apps, remove the "Apps" filter, search for Purchase Approval Workflow, and click Install.
  5. Go to Purchase → Configuration → Approval Matrix and create your first approval rule.
Quick-start tip: Use the Apply Policy Template wizard (Purchase → Configuration → Apply Policy Template) to load a pre-built three-level matrix in one click, then customise from there.
